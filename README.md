# il POD — Italian Podcast Awards

Sito ufficiale de **il POD**, gli Italian Podcast Awards, il premio italiano dedicato al podcasting.

## V edizione · Piacenza · 23 settembre 2026

Dal 2022 il POD è il principale riconoscimento italiano per il mondo del podcast. Con la quinta edizione il premio entra in una nuova fase: un Comitato Scientifico seleziona i titoli, le autocandidature vengono abolite e i premi si riducono a quattro — Podcast dell'Anno, La storia del podcast, Premio della Podcast Academy, Podcast Indie dell'Anno.

Il sito è anche l'archivio completo di tutte le edizioni passate con i vincitori per ogni categoria.

## Struttura

Il sito è una singola pagina HTML statica (`index.html`) che contiene tutto il CSS e il JavaScript inline. Non richiede build né dipendenze esterne, a parte i font Google (Instrument Serif, Inter, JetBrains Mono).

## Deploy

Il sito è pubblicato tramite GitHub Pages all'indirizzo [ilpod.it](https://ilpod.it).
